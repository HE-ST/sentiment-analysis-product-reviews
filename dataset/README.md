
# Dataset Instructions

This project uses the Cleanlab Amazon Reviews Dataset.

Source:
https://huggingface.co/datasets/Cleanlab/amazon-reviews

Download these two files:

- train.csv (5,000 reviews)
- test.csv (1,000 reviews)

Place both files in this directory.

Expected structure:

dataset/
    train.csv
    test.csv

Required columns:

- review_text
- label

Labels:
- positive
- negative

The dataset is distributed under the MIT license according to its Hugging Face dataset card.
